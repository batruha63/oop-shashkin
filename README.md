Лабораторная работа №1. Список дел

Среда разработки: visual studio, c#





В данной лабораторной работе мне предстояло сделать оконное приложение со списком дел. Проект полностью соответствует требованиям: компоненты модели "TodoItem", "TodoList" полностью изолированы от библиотек оконного интерфейса и не используют вывод графических окон самостоятельно.

В качестве дополнительного параметра задачи был выбран cрок выполнения с типом данных "DateTime?".



Инструкция по запуску:

1. Клонировать репозиторий в vs, выбрать ветку lab1;
2. Открыть файл решения проекта "TodoApp";
3. Компиляция проекта и его запуск.



Чек-лист:

1. Модель. Классы задачи и списка задач, поля закрыты, изменение только через методы. В модели нет окна и вывода. - выполнено
2. Окно. Поле ввода, кнопка «Добавить», список задач с отметкой выполнения и дополнительным полем. - выполнено
3. Операции. Выполнить, переименовать, удалить. Список обновляется сразу. - выполнено
4. Ошибки. Пустое название, действие без выбранной задачи, неверное значение доп. поля: сообщение, программа работает дальше. Пустое название запрещено в модели. - выполнено
5. Сохранение. Задачи сохраняются в JSON и загружаются при запуске. Нет файла: пустой список. - выполнено



Как устроен проект:

1. TodoItem - описывает сущность одной отдельной задачи. Содержит уникальный идентификатор `Guid`, текст заголовка, флаг выполнения, дату создания и дедлайн. Отвечает за инкапсулированное изменение своего состояния (методы Rename, ToggleDone).
2. TodoList - управляет коллекцией объектов TodoItem. Реализует методы добавления, удаления, поиска задач, хранения данных в JSON, а также вычисления отфильтрованных и отсортированных наборов данных.
3. MainForm - графическое представление. Отвечает исключительно за отображение данных, перехват действий пользователя и передачу команд в модель TodoList.
