Лабораторная работа №2. Графический редактор



Среда разработки: Visual Studio, C#, Windows Forms.



В данной лабораторной работе надо было создать простой графический редактор. Программа позволяет создавать графические фигуры с помощью мыши, выбирать цвет и толщину линий, сохранять и загружать готовые рисунки.



В качестве основных инструментов рисования были реализованы линия, прямоугольник, эллипс и карандаш для создания произвольных линий.



Инструкция по запуску:



1\. Клонировать репозиторий в Visual Studio и выбрать ветку lab2;

2\. Открыть файл решения проекта Paint;

3\. Выполнить компиляцию проекта и егозапуск.



Чек-лист:



1\. Модель фигур. Создан абстрактный базовый класс Shape, от которого наследуются классы конкретных фигур. - выполнено

2\. Фигуры. Реализованы классы LineShape, RectShape, EllipseShape и PencilShape. Каждый класс самостоятельно реализует отрисовку своей фигуры. - выполнено

3\. Рисование. Реализовано создание фигур с помощью мыши. - выполнено

4\. Настройки. Реализован выбор цвета и толщины линий. - выполнено

5\. Операции. Реализованы отмена последнего действия через кнопку и сочетание клавиш ctrl+z, а также очистка холста. - выполнено

6\. Сохранение. Реализовано сохранение рисунка в JSON-файл и загрузка рисунка из JSON-файла. - выполнено



Доп. задания:

1. Выделение и перемещение фигур. Реализована возможность выбирать созданные фигуры с помощью мыши, выделять их визуально и перемещать по холсту. — выполнено.

2\. Удаление фигур. — выполнено.

3\. Экспорт в PNG. — выполнено.

4\. Повтор действий. Реализована возможность повторять отменённые действия с помощью сочетания клавиш ctrl + y. — выполнено.

5\. Паттерн Command. Реализован паттерн «Команда» для управления действиями пользователя. Команды позволяют выполнять и отменять создание, перемещение, удаление фигур и очистку холста. — выполнено.

6\. Визуальное выделение инструмента. — выполнено.



Как устроен проект:



1\. Shape - абстрактный базовый класс для всех графических фигур. Содержит начальную и конечную точки, цвет, толщину линии и общий метод отрисовки.

2\. LineShape - класс, описывающий прямую линию. Реализует отрисовку линии между двумя точками.

3\. RectShape - класс, описывающий прямоугольник. Использует начальную и конечную точки для определения его размеров.

4\. EllipseShape - класс, описывающий эллипс. Реализует отрисовку эллипса в заданных границах.

5\. PencilShape - класс карандаша. Хранит последовательность точек, полученных при движении мыши, и соединяет их линиями.

6\. Drawing - управляет коллекцией созданных фигур. Отвечает за добавление, удаление, очистку, отрисовку, подготовку данных для сохранения и загрузку рисунка.

7\. ShapeFactory - фабрика фигур. Создаёт объекты нужного типа в зависимости от выбранного инструмента.

8\. ShapeData - класс хранения данных фигур для сериализации и десериализации JSON.

9\. Form1 - главное графическое окно приложения. Обрабатывает действия пользователя, выбор инструментов, рисование мышью, настройки и работу с файлами.

10\. ICommand — интерфейс команд. Определяет методы выполнения и отмены действий.

11\. AddShapeCommand — команда добавления фигуры.

12\. MoveShapeCommand — команда перемещения фигуры.

13\. DeleteShapeCommand — команда удаления фигуры.

14\. ClearDrawingCommand — команда очистки холста.

15\. CommandManager — управляет историей команд, обеспечивает отмену и повтор действий.
